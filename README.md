# Discord Pomodoro Bot

A Discord bot that uses the Pomodoro technique to help users focus during voice calls.
The bot automatically mutes and unmutes users in a voice channel based on work and break intervals.

This project is still under development. Future plans include packaging the bot as an executable file and/or an app.

## Features
- Voice-based Pomodoro sessions
- Automatic mute/unmute during focus and break phases
- Auto-mute users who join during a focus session
- Simple text commands

## Commands 
!join  
!pomodoro <work_minutes> <break_minutes>  
!stop  
!leave  

## Status
🚧 Work in progress

# Bot Pomodoro para Discord
Um bot para Discord que utiliza a técnica Pomodoro para ajudar usuários a manter o foco durante chamadas de voz.
O bot muta e desmuta automaticamente os usuários em um canal de voz com base nos intervalos de trabalho e pausa.
Este projeto ainda está em desenvolvimento. Planos futuros incluem tornar o bot um arquivo executável e/ou um app.
## Funcionalidades
- Sessões Pomodoro baseadas em canal de voz
- Mute/unmute automático durante as fases de foco e pausa
- Mute automático de usuários que entram durante uma sessão de foco
- Comandos de texto simples
## Comandos
!join  
!pomodoro <minutos_trabalho> <minutos_pausa>  
!stop  
!leave
